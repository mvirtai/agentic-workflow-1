LANGUAGE SUPPORT
----------------

Go
  • Min version: 1.21
  • Build: go build -o bin/<name>
  • Test: go test -v ./...
  • Lint: go vet ./...
  • Linter: golangci-lint
  • Coverage: Codecov
  • CI/CD: github-actions-go.yml

Python
  • Min version: 3.9
  • Package manager: uv
  • Build: uv build
  • Test: uv run pytest -v
  • Lint: uv run ruff check .
  • Type check: uv run mypy .
  • Coverage: Codecov
  • CI/CD: github-actions-python.yml

Node.js
  • Min version: 18
  • Package manager: pnpm
  • Build: pnpm build
  • Test: pnpm test --run
  • Lint: pnpm lint
  • Type check: pnpm tsc --noEmit
  • Coverage: Codecov
  • CI/CD: github-actions-node.yml

React
  • Min version: 19.3 (with React Compiler)
  • Package manager: pnpm
  • Build: pnpm build
  • Test: pnpm test --run
  • Lint: pnpm lint (with React Compiler rules)
  • Type check: pnpm tsc --noEmit
  • Conventions:
    - 'use server' / 'use client' directives
    - Prefer Server Components
    - useAction() for forms
    - NO: useEffect, useRef, useLayoutEffect
    - YES: Derived state, Suspense
  • Coverage: Codecov
  • CI/CD: github-actions-node.yml

CONFIGURATION INHERITANCE
--------------------------

Project Config (~/.agentic/projects/<name>.yaml)
    ↓ (extends)
Global Defaults (~/.agentic/config/defaults.yaml)

Project-specific settings override global defaults.
Example:
  • Global: go min_version = 1.21
  • Project override: go min_version = 1.22

  ls -la ~/.agentic/                    # Directory structure

  nano ~/.agentic/config/defaults.yaml
